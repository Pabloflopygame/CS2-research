Esta rama del trabajo fue abandonada después de ver que las limitaciones de steam limitaba mucho nuestro alcanze de cuantos usuarios podríamos analizar.
Sobrellevar estas limitaciones sería una inversión importate de tiempo y potencialmente dinero (si quisieramos alquilar varias máquinas en una nube).
Por lo que simplemente abandonamos estudiar la población y nos centramos en el mercado, todo esto dicho, mantenemos el código como deprecated en caso que algún otro usuario quiera retornar nuestra investigación que tenga esta rama como base (en caso que el tenga los recursos y tiempo para llevarla a cabo).

Ahora, borramos la documentación para que se tenga claro que esto es deprecated y no debe ser usado en el trabajo principal. Pero el código esta bien documentado y es corto por lo que no debería presentar problemas para usuarios que quieran retornar esta rama.
